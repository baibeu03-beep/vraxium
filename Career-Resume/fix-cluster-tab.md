# .cluster-tab 비율/잘림 문제 수정 요청

## 현재 문제

`.cluster-tab` 영역이 브라우저 비율(확대/축소)에 따라 일관성 없이 동작한다:

- **100% 비율**: 맨 우측 탭이 살짝 잘림
- **축소 시 (90%, 80% 등)**: 축소되는 만큼 더 잘림 (맨 우측 탭의 'working lev' 까지만 보임)
- **확대 시 (125%, 150% 등)**: 우측에 불필요한 여백이 남음
- 즉, 비율에 따라 탭이 잘리기도 하고, 여백이 남기도 하는 상태

## 기대 동작

- **어떤 비율에서든** `.cluster-tab` 내 탭들의 간격이 균등하고 일관되어야 한다.
- 페이지 내 다른 콘텐츠 영역들은 비율 변경 시 자연스럽게 대응하고 있다. `.cluster-tab`도 **다른 콘텐츠 영역들과 동일한 방식으로** 비율 변경에 대응해야 한다.
- 탭이 잘리면 안 되고, 불필요한 여백이 남아서도 안 된다.

## 사전 조사

```bash
# 1. .cluster-tab 관련 스타일 전부 찾기
grep -rn "cluster-tab\|clusterTab\|cluster_tab" --include="*.css" --include="*.scss" --include="*.module.css" --include="*.tsx" --include="*.jsx"

# 2. .cluster-tab의 부모 컨테이너 스타일 찾기 (width, max-width, overflow, padding 등)
grep -rn "cluster-tab\|clusterTab" --include="*.tsx" --include="*.jsx"
# → 위 결과에서 부모 컨테이너의 클래스명을 확인한 뒤, 해당 클래스의 스타일도 검색할 것

# 3. .cluster-tab 내부 개별 탭 아이템의 너비 설정 찾기
grep -rn "cluster-tab" --include="*.css" --include="*.scss" --include="*.module.css" -A10

# 4. 다른 콘텐츠 영역이 비율 변경에 정상 대응하는 방식 확인 (비교 참고용)
# → 정상 동작하는 다른 섹션의 width 설정 방식을 확인하여 .cluster-tab에도 동일하게 적용할 것
```

## 수정 방향

1. 먼저 `.cluster-tab`과 **정상 동작하는 다른 콘텐츠 영역**의 너비 설정 방식을 비교 분석한다.
2. 다른 콘텐츠 영역에서는 비율 변경 시 잘림/여백 없이 자연스럽게 동작하고 있으므로, 그 방식과 `.cluster-tab`의 차이점을 파악한다.
3. `.cluster-tab`의 너비 설정을 다른 정상 동작하는 영역과 동일한 방식으로 수정한다.
4. 개별 탭 아이템의 너비가 `px` 고정값이라면 `%` 또는 `flex` 기반으로 변경하여 부모 너비에 맞게 균등 배분되도록 한다.
5. 부모 컨테이너에 `overflow: hidden`이 있어서 잘리는 것이라면, 너비 계산을 수정하여 overflow 자체가 발생하지 않도록 한다.

## 확인 기준

- zoom 75%, 80%, 90%, 100%, 110%, 125%, 150% 모두에서:
  - 모든 탭이 잘리지 않고 온전히 보임
  - 우측에 불필요한 여백이 없음
  - 탭 간 간격이 균등하고 일관됨
  - 다른 콘텐츠 영역과 동일한 비율로 대응함
