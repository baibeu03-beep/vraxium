# 인덱스 위치 고정 작업 — 프롬프트 가이드

다음에 유사한 작업(카드/리스트에서 숫자/기호 위치가 자릿수에 따라 밀리는 문제)을 할 때 참고하세요.

---

## 1. 문제 정의 방법

**"이 카드 안에서, 숫자의 자릿수가 다를 때 뒤에 오는 기호(%, /, 괄호 등)의 x좌표가 밀린다"**

스크린샷에 **세로 기준선(빨간 수직선)**을 그어서, "이 선 위에 같은 요소가 와야 한다"고 보여주면 가장 명확합니다.

---

## 2. 핵심 구현 원리

```
숫자에 고정 너비(min-width) + 우측 정렬(text-align: right)
→ 숫자 뒤의 기호 위치가 자동으로 고정됨
```

```
세자리: [100]%   ← 꽉 참
두자리: [ 75]%   ← 왼쪽 여백
한자리: [  8]%   ← 왼쪽 여백 더 큼
보이드: [  -]%   ← 보이드도 동일
         ↑ % 위치는 항상 같음
```

**SCSS에 공통 클래스 정의:**

```scss
.num-4 { display: inline-block; min-width: 4ch; text-align: right; }
.num-3 { display: inline-block; min-width: 3ch; text-align: right; }
.num-2 { display: inline-block; min-width: 2ch; text-align: right; }
.num-1 { display: inline-block; min-width: 1ch; text-align: right; }
```

**TSX에서 숫자를 `<span>`으로 감싸기:**

```tsx
// 변경 전 — 숫자가 직접 렌더링되어 밀림
<span>실무 정보 강화율 {rate}%( {completed}/{total})</span>

// 변경 후 — 숫자를 고정 너비 span으로 감쌈
<span>실무 정보 강화율 </span>
<span className="num-3">{rate}</span>
<span>%( </span>
<span className="num-2">{completed}</span>
<span>/</span>
<span className="num-2">{total}</span>
<span>)</span>
```

## 3. 프롬프트 작성 시 반드시 포함할 것

### A. 요소별 최대 자릿수 표

```
| 요소 | N의 최대 자릿수 | 사용할 클래스 |
|------|-------------|------------|
| 강화율 N% | 3자리 (100) | num-3 |
| (N/N) 분자 | 2자리 (99) | num-2 |
| (N/N) 분모 | 2자리 (99) | num-2 |
| 명성도(FM) | 4자리 (9999) | num-4 |
| N / N 주차 | 2자리 (99) | num-2 |
| 단감/인절미/어흥 | 3자리 (999) | num-3 |
```

**이 표가 없으면 Claude Code가 자릿수를 임의로 결정하거나 누락합니다.**

### B. 고정되어야 하는 기호/요소 목록

```
- %의 x좌표가 모든 카드에서 동일
- (의 x좌표가 동일
- /의 x좌표가 동일
- )의 x좌표가 동일
- progress-bar의 시작점/끝점 동일
- leaf 아이콘의 시작점 동일
- '개 중', '개' 텍스트 위치 동일
```

### C. 동적 너비 vs 고정 너비 구분

```
- 고정: 시작점과 끝점이 모두 같아야 하는 요소 → 고정 너비(width)
  예: N / N 주차, progress-bar

- 동적: 시작점은 같고 끝점은 텍스트에 따라 다른 요소 → fit-content
  예: info-group의 role 박스 ('일반' < '운영진(앰배서더)')
```

### D. 더미 데이터 자릿수 분산

```
각 사용자 안에서 1자리/2자리/3자리/보이드를 랜덤으로 섞어서,
한 카드만 봐도 위치 고정이 되는지 확인 가능하게.
```

### E. 기존 프로젝트 내 참고 코드 지정

```
이미 동일한 패턴이 적용된 곳이 있다면 해당 코드를 먼저 확인하고 따르라고 명시.
예: "cluster-4-1의 area-6-circles, area-7-progress 스타일을 참고할 것"
```

## 4. 프롬프트 템플릿

```markdown
# [대상 컴포넌트] — 인덱스 위치 고정

## 절대 보호 원칙
요청 범위 외 코드 변경 금지. 사이드이펙트 금지.

## 핵심 원칙
숫자는 항상 우측 정렬. 자릿수가 적으면 왼쪽 여백, 최대 자릿수이면 여백 없음.

## 참고 코드
[프로젝트 내 이미 적용된 곳]의 스타일을 먼저 확인하고 동일 패턴을 따를 것.

## SCSS 공통 클래스 추가
.num-N { display: inline-block; min-width: Nch; text-align: right; }

## 요소별 최대 자릿수 + 적용 클래스
| 요소 | 최대 자릿수 | 클래스 |
|------|----------|--------|
| ... | ... | ... |

## 기호 위치 고정 목록
- %의 x좌표 동일
- /의 x좌표 동일
- ...

## 동적 너비 요소 (fit-content)
- [요소명]: 시작점 고정, 끝점은 텍스트에 따라 동적

## 더미 데이터
각 사용자별로 자릿수를 랜덤 분산 (1자리/2자리/3자리/보이드 혼합)

## 확인 기준
- 다양한 자릿수에서 기호 위치 동일한지
- 보이드(-)일 때도 동일한지
- 다른 요소 변경 없는지
```

## 5. 자주 발생하는 실수와 방지법

| 실수 | 방지법 |
|------|--------|
| CSS만으로 해결하려 함 (효과 없음) | **TSX에서 숫자를 `<span>`으로 감싸는 것이 핵심**이라고 명시 |
| 자릿수를 임의로 결정 | **요소별 최대 자릿수 표를 반드시 포함** |
| 숫자 감싸기 하면서 dot/텍스트 위치도 변경 | **"숫자 감싸기 외 변경 금지"** 명시 |
| 고정 너비와 동적 너비를 혼동 | **어떤 요소가 고정이고 어떤 요소가 동적인지 명확히 구분** |
| 하나의 자릿수로만 더미 데이터 생성 | **"각 사용자 내에서 자릿수 랜덤 분산"** 명시 |
| 기존 코드 참고 없이 새로운 방식 사용 | **참고할 기존 코드 경로를 구체적으로 지정** |

---

## 6. 검증 방법

1. **4명 사용자의 카드를 나란히 비교** — 세로 기준선이 일치하는지
2. **1자리/2자리/3자리/보이드 모두 포함된 카드에서** — 한 카드 안에서도 기호 위치 동일한지
3. **브라우저 DevTools에서 x좌표 측정:**

```js
document.querySelectorAll('.num-3').forEach((el, i) => {
  console.log(`num-3[${i}]:`, el.textContent, 'right:', el.getBoundingClientRect().right);
  // right 값이 모두 동일해야 함 → 뒤에 오는 기호 위치 동일
});
```
